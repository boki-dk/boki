# boki.dk

## Due to a cease and desist, boki.dk is now a shell front-page, and no longer shows real estate listings.

Boki.dk is a real estate website created as a **student project** for DTU. Boki (no longer) scrapes listings from Home.dk and Nybolig.dk, and lists them on www.boki.dk.

Scraping functionality, database and frontend are found on this repo
